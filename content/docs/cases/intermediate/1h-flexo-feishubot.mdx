- 夸夸机器人

## 飞书机器人类型简介

飞书机器人分为两种：
- **自定义机器人**：只能在群聊中使用，功能较为固定，主要用于消息推送。
- **应用机器人**：功能丰富，支持对话互动等多种能力，需要企业账户。

详细说明见：[飞书机器人类型教程](https://github.com/Beatrueman/FeishuBot)

## 云服务器部署 Python 服务指南

本节介绍如何在云服务器上部署和持续运行你的飞书机器人 Python 程序。

### 1. 准备服务器环境

```bash
sudo apt update && sudo apt upgrade -y  # 更新系统包
sudo apt install -y git python3 python3-pip python3-venv  # 安装必要工具
```

### 2. 包管理器 uv（可选）

#### Windows 安装
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

#### Linux 安装
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

> 也可以在 Python 虚拟环境下用 pip 安装 uv：
> ```bash
> pip install uv
> ```

### 3. 克隆 GitHub 代码

```bash
git clone <你的项目地址>
cd <项目目录>
```

### 4. 创建并激活虚拟环境

```bash
python3 -m venv venv  # 创建虚拟环境
source venv/bin/activate  # 激活虚拟环境
deactivate  # 退出虚拟环境
```

### 5. 安装依赖

```bash
pip install -r requirements.txt  # 安装依赖
pip install pipreqs  # 安装 pipreqs 工具
pipreqs ./ --encoding=utf8 --force  # 生成 requirements.txt
```

#### 扩展：使用 conda 创建虚拟环境

```bash
conda create --name myenv python=3.8  # 创建
conda activate myenv  # 激活
conda env list  # 查看所有环境
conda remove --name myenv --all  # 删除
```

> **常见问题**
> - 创建失败 CondaValueError: Malformed version string '~': invalid character(s).
>   - 检查 C:\Users\xxx\.condarc 文件内容，建议将 https 改为 http，或直接清空内容。
>   - 示例 .condarc：
>     ```yaml
>     ssl_verify: false
>     channels:
>       - conda-forge
>       - https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/
>       - https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
>       - https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge/
>       - https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/msys2/
>       - https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/bioconda/
>       - https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/menpo/
>       - https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/pytorch/
>       - defaults
>     show_channel_urls: true
>     ```

### 6. 配置环境变量

```bash
cp .env.example .env  # 创建 .env 文件
vim .env  # 编辑 .env
iconv -f UTF-16LE -t UTF-8 .env > .env.utf8  # 解决编码问题
mv .env.utf8 .env
file -i .env  # 应显示 .env: text/plain; charset=utf-8
```

### 7. 测试运行

确保虚拟环境已激活：
```bash
source venv/bin/activate
python main.py  # 启动服务，检查依赖和代码
```

依赖包版本管理：
```bash
pip show lark_oapi  # 查看版本
pip uninstall -y lark-oapi
pip install lark-oapi==1.4.13  # 指定版本
```

### 8. 设置服务持久化运行（Supervisor）

#### 安装 Supervisor
```bash
sudo apt install -y supervisor
```

#### 创建 Supervisor 配置
```bash
sudo vim /etc/supervisor/conf.d/feishu-bot.conf
```

内容示例：
```ini
[program:feishu-bot]
directory=/home/ubuntu/projects/feishu-bot
command=/home/ubuntu/projects/feishu-bot/venv/bin/python main.py
autostart=true
autorestart=true
stderr_logfile=/var/log/feishu-bot.err.log
stdout_logfile=/var/log/feishu-bot.out.log
user=ubuntu
environment=PYTHONUNBUFFERED=1
```

#### 启动服务
```bash
sudo supervisorctl reread  # 重新加载配置
sudo supervisorctl update
sudo supervisorctl start feishu-bot  # 启动服务
```

#### 检查服务状态
```bash
sudo supervisorctl status feishu-bot
sudo tail -f /var/log/feishu-bot.out.log
```

> 这样可以保证你的机器人服务在云服务器上持续稳定运行。
