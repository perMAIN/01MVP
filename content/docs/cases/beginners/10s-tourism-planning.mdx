# 10秒生成旅游规划

本文将介绍如何使用Cursor和Claude快速生成旅游行程规划，包括两种方案：纯对话生成和使用高德地图MCP服务。

## 方案一：纯对话生成

### 在线示例
🔗 [查看示例](https://67da40a9d39fe09f22780449--exquisite-wisp-d64d56.netlify.app/)

### 使用方法

只需一句话，就能生成完整的旅行计划。以香港-东京旅行为例：

```chat
你接下来请帮我搜索一下网络，然后我4月1号到4月5号从香港想要去日本旅行，请帮我做一下详细的规划，注意你需要搜索相关的内容，然后查到相关的酒店机票的，然后写成一个html页面
```

Claude会自动：
1. 搜索相关旅游信息
2. 查询机票和酒店数据
3. 生成行程安排
4. 输出美观的HTML页面

### 优势
- 快速：一句话即可完成规划
- 全面：包含交通、住宿、景点等信息
- 智能：自动优化行程安排
- 美观：直接生成格式化的HTML页面

## 方案二：使用MCP服务

### 环境准备

1. 克隆高德地图MCP项目：
> 使用MCP教程中创建的高德MCP服务，也可以使用其他
```bash
git clone https://github.com/perMAIN/gaode.git
```

2. 按照[MCP教程中高德地图MCP使用示例](/docs/tools/mcp/mcp-usage-guide#63-高德地图mcp使用示例)配置和启动服务

### 在线示例
🔗 [查看示例](https://poetic-stardust-3e5e8c.netlify.app/)

### 使用方法

使用高德地图MCP服务可以获得更专业的路线规划：

```chat
使用高德的MCP服务，请帮我规划北京三日游，包含故宫、长城、颐和园、天坛和鸟巢，写成一个html页面
```

Claude会：
1. 调用高德地图API获取实时数据
2. 智能规划最优路线
3. 计算交通时间和距离
4. 生成包含地图的HTML页面

### 优势
- 精准：使用高德地图专业数据
- 实时：获取实时路况和POI信息
- 可视化：包含交互式地图
- 专业：提供详细的路线导航

## 最佳实践

1. **选择合适的方案**
   - 快速规划：使用纯对话方案
   - 精确导航：使用MCP方案

2. **优化提示词**
   - 明确时间范围
   - 指定预算限制
   - 说明特殊需求
   - 要求输出格式

3. **善用MCP功能**
   - 路线优化
   - 景点推荐
   - 交通规划
   - 实时路况

## 常见问题

1. **生成的HTML无法打开**
   - 检查文件编码
   - 确保资源路径正确
   - 使用本地服务器预览

2. **MCP服务连接失败**
   - 验证API Key
   - 检查网络连接
   - 确认服务状态

3. **规划结果不理想**
   - 完善提示词
   - 调整规划参数
   - 手动微调结果
